# 对外接口约定

1. **参数校验在边界做**：外部输入先校验类型和范围，再交给领域逻辑。
2. **错误响应统一结构**：`{"error": {"code": "...", "message": "..."}}`，不把栈信息直接吐给调用方。
3. **不改已有字段语义**：新增能力用新字段，不复用旧字段。
4. **每个新接口至少一个测试**，放在 `tests/`。
5. **日志不打印敏感信息**（token、密码、身份证号等）。

> 这是**咨询性**约束（让违规变罕见，但不强制）。
> 必须 100% 守住的规则（如"不许改测试文件"）请用 Hooks 兜底——见 `.qoder/hooks/`。
